# Sistema de Registro de Usuarios - Tarea 1 - Grupo 3

## Descripción
Aplicación básica en Java usando la librería Swing (`JOptionPane`) para capturar y visualizar datos de usuarios de forma segura.

## Cómo ejecutar
1. Abrir el proyecto en NetBeans.
2. Acceder al proyecto Tarea1-Progra2, específicamente a la clase `Tarea1Progra2.java`.
3. Presionar **F6** o hacer click en el botón de **Play** para ejecutar la clase principal `Tarea1Progra2.java`.

## Roles
*   **Derek**: Diseñó la interfaz base, la captura de los 5 datos solicitados y la estructura del resumen.
*   **Matias**: Implementó del manejo de excepciones (`try-catch`), la validación de datos numéricos y el aseguramiento de flujo.
